# Oryon Remote 🚗📱

A simple Android remote controller application built using Java in Android Studio.

This app is designed to control a robotic car using directional buttons such as:

- Forward
- Backward
- Left
- Right
- Stop

---

## ✨ Features

- Forward movement control
- Backward movement control
- Left turn control
- Right turn control
- Stop button
- Simple and clean UI
- Beginner-friendly Android project

---

## 🛠 Technologies Used

| Technology | Purpose |
|------------|---------|
| Java | App Logic |
| XML | UI Design |
| Android Studio | Development IDE |
| Bluetooth (Planned) | Communication |
